# Solelot - מפת מיחזור סוללות בישראל

[![Live Site](https://img.shields.io/badge/Live%20Site-zeevmala.github.io%2Fsolelot-00796B?style=flat-square)](https://zeevmala.github.io/solelot/)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue?style=flat-square)](LICENSE)

A map of public battery collection points in Israel. The page is in Hebrew, right-to-left.

Live site: [zeevmala.github.io/solelot](https://zeevmala.github.io/solelot/)

## Features

- **Map**: Leaflet with marker clustering.
- **Search**: by name, address or city, with suggestions.
- **Nearest point**: the locate button frames you together with the closest collection point and shows distances.
- **Navigation**: Google Maps and Waze links on every point.
- **Basemaps**: OpenStreetMap standard tiles, and a light style (the same tiles, desaturated in CSS).
- **PWA**: installable. After the first visit the page and the points load offline.
- **Accessibility**: keyboard navigation and ARIA labels.
- **Phones**: the detail panel becomes a bottom sheet on small screens.

Opening hours are not shown: the source has none (see [Data](#data)).

## Run locally

Serve the folder with any static file server. The service worker needs `http://localhost` or HTTPS; it does not run from `file://`.

```bash
git clone https://github.com/Zeevmala/solelot.git
cd solelot
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Checks

```bash
bash .factory/check.sh
```

One command runs every check and ends with `GATE PASSED` or a line starting with `FAIL`. It needs Node 22, git and Chrome or Chromium (set `CHROME_BIN` if the browser is not on the `PATH`). It uses no network. The steps:

1. Every script parses.
2. Every JSON file parses.
3. `node --test test-scraper.js test-validate.js`: tests of the real scraper functions and of the data checks.
4. `node validate_data.js`: data-quality checks on `locations.json`.
5. `node cartowolf/check-colors.mjs style.css app.js index.html`: no hand-written colours.
6. Site check: every file the service worker precaches exists, the page loads nothing that is not precached, no path starts at the domain root, and the manifest icons have the sizes they claim.
7. `test.html` and `test-map.html` run in headless Chrome with no failed test.
8. Each function copied into a test page is identical to the function in `app.js`.
9. `STATIC_CACHE` in `sw.js` changed if a cached file changed since the default branch.

The two test pages also run by hand: with the local server running, open `http://localhost:8000/test.html` and `http://localhost:8000/test-map.html`. They test copies of `app.js` functions, which is why step 8 exists.

## Data

Schools are left off the map on purpose: a collection bin inside a school is not open to the public. Colleges and universities are shown.

`locations.json` holds every point:

```json
{
  "locations": [
    {
      "id": 343489,
      "name": "סופר ברקת - קיבוץ גלויות 106",
      "address": "קיבוץ גלויות 106, תל אביב",
      "city": "תל אביב",
      "type": "store",
      "chain": "other",
      "lat": 32.047942,
      "lng": 34.777016,
      "hours": "בדוק באתר"
    }
  ]
}
```

- `id` is the MAI marker id. It stays the same between refreshes. Ids 1–99 are reserved for `facilities.json`.
- `type` is `store` (collection point) or `facility` (recycling plant).
- `chain` is set by the scraper. The page does not use it.
- `hours` is the placeholder `"בדוק באתר"` on every record. The page hides it.
- `description` is optional and is shown when present.

### Refreshing the data

```bash
node scraper.js        # fetch MAI, apply data_overrides.json, merge facilities.json
node validate_data.js  # must end with ALL CHECKS PASSED
```

- **Collection points** come from the [MAI](https://mai.org.il) map API (live map `5`, category `12` = batteries). Unnamed markers, markers flagged as inactive, and repeats are dropped.
- **`facilities.json`** is empty on purpose: recycling plants are not public drop-off points. An entry added there (type `facility`, id 1–99, with a `description`) appears with an orange factory pin and brings back the legend.
- **`data_overrides.json`** holds per-id corrections for MAI records whose city or coordinates are wrong. The position checks in `validate_data.js` list new suspects after each refresh.
