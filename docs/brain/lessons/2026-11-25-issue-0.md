# A green test page proved nothing here: test the real functions, and send every build to a reviewer that did not write it

**What happened:** Both browser test pages passed (35/35, 80/80) while search showed 532 points for a city with 138, because the pages tested stale copies of the functions. Later, the rule that removes points stacked on one coordinate passed its own 40 tests and still removed all five Dizengoff Center shops: one record spelled the street without a yod. A fresh reviewer found it by reading the list of dropped groups in the real data; the builder's tests used clean made-up streets.

**Rule:** When a rule deletes data, print every id it deletes and read the list from a real run before merging; add real cases from that list to the tests. Keep copied test functions identical to `app.js` (gate step 8 checks it). There was no issue number for this work, so the ticket is 0.
