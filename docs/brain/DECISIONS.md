# Decisions

Decisions for this project, and why. Append; never edit an entry. To reverse one, add a new entry that names the one it replaces. Decisions that apply to every project live in the factory's `brain/DECISIONS.md`.

Format: `YYYY-MM-DD — decision. Why. (replaces YYYY-MM-DD, if it does)`

- 2026-11-25 — No build tools: plain HTML, CSS and JavaScript, no npm, no bundler. The site is one static page and its owner is learning to code; every extra tool is something to break. (recorded from `CLAUDE.md`)
- 2026-11-25 — No recycling facilities on the map. Batte-Re and RE-CAR were added and then removed at the owner's request; `facilities.json` stays empty and the app keeps support for the type. (recorded from `CLAUDE.md`)
- 2026-11-25 — `locations.json` is written only by `scraper.js`. Single-record fixes go in `data_overrides.json`. An earlier hand rebuild undid the name cleanup. (recorded from `CLAUDE.md`)
- 2026-11-25 — Colours come from `cartowolf/tokens.css`, which is copied from the factory's `design/` and never edited here. One source for every project's look. (recorded from `CLAUDE.md`)
- 2026-11-25 — The page is fixed to the light theme. The OpenStreetMap basemap is a light picture and the dark pin colours are made for a dark map. (recorded from `CLAUDE.md`)
- 2026-11-25 — The project is connected to the factory layout: `.factory/` gate, `docs/designs/`, `docs/brain/`. The gate uses Node's built-in test runner and the existing check scripts, so "no npm" still holds.
- 2026-11-25 — Work is organised as six team leads and one orchestrator, described in `docs/teams.md`. Leads audit in parallel and read-only; builds run one at a time; a fresh agent reviews. Parallel builds in one working tree race on `app.js`, `sw.js` and the cache version.
- 2026-11-25 — Points that share one exact coordinate but name different streets are removed by the scraper (162 points at this date). The source's geocoder puts unfound addresses at the city centre, and nobody can tell which of the stacked points is right; a missing point costs less than sending someone to the wrong place. Same street in two spellings, and a no-street group inside one village, are kept.
- 2026-11-25 — The map filter matches by substring first and falls back to near-spelling only when nothing matches, with the allowed difference scaled to the length of the text. Two letter edits on a four-letter city name matched hundreds of other places.
- 2026-11-25 — A failed service worker update must not install. The old worker and cache stay until every file of the new one is fetched; Leaflet is on the must-have list. Cost: a first visit while unpkg is down gets no offline copy until the next visit.
- 2026-11-25 — The page credits MAI as the data source in the map attribution, and the README says the data is not covered by the MIT licence. Whether MAI's terms allow republishing is not known from the repository and is the owner's question to settle.
- 2026-11-25 — Marker redraws are serialised: `updateMarkers` never starts a new add while one is running; it asks for one redraw when the running add ends. On a slow phone the cluster layer kept adding the old list into the cleared layer, so the map showed hundreds of points that did not match the search box.
- 2026-11-25 — Known weak spot, accepted for launch: showing a picked point that sits inside a cluster goes through the cluster layer's `zoomToShowLayer`, which leaves listeners behind and ignores map moves during its animation. `zoomToClusteredMarker` works around both by recording the listeners it adds and by repeating `moveend` after the animation. It is covered by `test-smoke.js` (two quick picks, a search during the zoom). The simpler design is to draw the selected point on its own layer above the clusters and drop `zoomToShowLayer`; do that the next time this code is touched.
- 2026-11-25 — Schools are not shown (owner's decision). A collection bin inside a school is not open to the public, and no record has opening hours. The scraper skips names and place fields that say school, high school, junior high, yeshiva, ulpana, talmud torah or kindergartens (517 markers at this date); colleges and universities stay. 4,115 → 3,627 points.
- 2026-11-25 — Leaflet and Leaflet.markercluster are served from `vendor/` in this repository (owner's decision), not from unpkg. A CDN outage no longer breaks the first visit or the offline install, and the CSP names no third-party script host. (replaces the "Cost" sentence of the 2026-11-25 service worker entry: unpkg is no longer involved)
- 2026-11-25 — Not decided by the owner, left as they are: whether MAI's terms allow republishing, and the points of chains that may have closed (מגה and others).
- 2026-11-26 — The thumbs-up button sends a confirmation through the existing Google Form (owner's decision). A press opens the report form filled in with the point, and the name field starts with "✔ הנקודה קיימת:" so the owner can tell a confirmation from a problem report. The form has no field for this yet and the page cannot write anywhere else (no backend). Better later: a choice question in the form ("קיימת" / "בעיה"), prefilled by its entry id.
- 2026-11-26 — The map is strictly for recycling batteries (owner's decision). It does not say what else a point accepts: MAI's categories 14 and 15 (small and large electrical items, 1,288 points) are not shown, and the scraper keeps reading the category only to select battery points (category 12). A point that accepts batteries stays on the map whatever else it accepts.
- 2026-11-26 — One shop listed twice is merged by the scraper: same chain (first part of the name, with the brand for a fuel station; "רמי לוי - תקשורת" is "רמי לוי"), at most 50 m apart, same street or one without a house number; the lower id stays. Two different house numbers are never merged (אבי סופר, אלנבי 113/122/124, three shops within 23 m). Municipal points are not a chain. Validator check 25 catches the same chain at the same address up to 100 m; those pairs are excluded by override.
- 2026-11-26 — Validator warning 14d (same street in one city, nearest other point on it over 1.5 km) flags only points with a house number: on the old file this kept all 14 confirmed wrong pins and cut 75 flags to 41. Position warnings already looked at go in `REVIEWED_OK` in `validate_data.js`, per check, with the date and why, so a refresh lists only new ones. An open question for the owner may sit there with a note; a wrong pin may not.
- 2026-11-26 — The place is left out of a point's address when its name already ends with that place (811 repeats on the old file), unless the place is all the address has besides the city. A trailing "N-" in MAI's text is a floor below ground and is kept as "(N-)", the form MAI uses elsewhere.
- 2026-11-26 — The point whose details are open is drawn as a second, larger pin on its own layer above the clusters; the map flies to it once. `zoomToShowLayer`, `zoomToClusteredMarker`, `cancelReveal`, `revealMarker` and `whenMarkersAdded` are gone. Cost: the point's ordinary pin can still be counted in a cluster bubble next to the selected pin. (replaces the 2026-11-25 "known weak spot" entry; the "marker redraws are serialised" entry still holds)
- 2026-11-26 — The open point is in the address as `?id=<id>`, a picked city as `?city=<name>`; both are checked against the loaded data and anything else opens the plain map. Opening a point is one browser-history step and the next point replaces it, so Back closes the details and stays on the page; a link that opens a point lands on the plain page plus that one step. A city pick or a search change replaces the address, never adds a step.
- 2026-11-27 — Points inside places the public cannot freely enter are left out, like schools (owner's decision): an air force base, the national police headquarters and a pre-army academy (343333, 344808, 345833).
- 2026-11-27 — The two navigate buttons, Waze and Google Maps, are equal and both filled (owner's decision). People use the app they already have; Waze is driving only, Google Maps also walks.
- 2026-11-27 — The details sheet shows the kind of point in one line: fuel station, shop or municipal point (owner's decision). The scraper writes a `kind` field computed from the name and MAI's categories; it replaces `chain`, which the app never read. Category 14 is used only as a signal for "municipal"; the map still does not say what else a point accepts.
- 2026-11-27 — A search for a chain that MAI does not list (סופר פארם, אופיס דיפו, KSP, פלאפון, סלקום) says so plainly instead of the generic "no results" (owner's decision). People otherwise think the map is broken.
- 2026-11-27 — Points inside places the public cannot freely enter are left out, like schools (owner's decision). Three are excluded by id in `data_overrides.json`: 343333 מחנה רמון (an air force base), 344808 inside the national police headquarters (חיים בר לב 1, ירושלים) and 345833 a pre-army academy (כפר יונה). They are excluded one by one rather than by a name rule, because the same words name open places: fuel stations "מול מחנה 80" (344419) and "כיכר המשטרה" (344338, 344345). 3,579 → 3,576 points.
- 2026-11-27 — Each collection point has a `kind`: `fuel`, `shop` or `municipal` (owner's decision), shown to users as one short line. The scraper reads it from the raw MAI business name and categories (`pointKind`); category 14 is used only as a sign of a municipal point. A point with no business name, or whose name is only its address, gets no `kind` (33 of 3,576): there is nothing to tell it by, and a guess shown to users is worse than no label. `kind` replaces `chain`, which the page never read. Counts: municipal 1,268, shop 1,489, fuel 786. A seeded sample of 40 (14 fuel, 13 shop, 13 municipal) was all correct. The validator fails on any other value and when under 95 % of points have one. (replaces `chain` in the schema)
- 2026-11-27 — "Nearest to me" is the first action on a phone: a filled pill "הנקודה הקרובה אליי" in the bottom right (48 px, the thumb zone), round after the first fix; the +/− buttons are hidden on touch phones (`pointer: coarse` and ≤ 768 px), where pinch zooms, and kept on desktop. (design great-map A7)
- 2026-11-27 — Waze and Google Maps are equal: two filled buttons of the same size, "ניווט ב-Waze" and "ניווט ב-Google Maps" (owner's decision). Neither is the main one; Waze is driving only.
- 2026-11-27 — A point's kind is shown as one short line in its details when the record has the optional `kind` field (fuel → תחנת דלק, shop → חנות, municipal → נקודת איסוף עירונית), nothing when it is absent or unknown (owner's decision). It is not a filter.
- 2026-11-27 — A search that finds nothing and names a chain MAI does not list (סופר פארם, אופיס דיפו, KSP, פלאפון, סלקום, also typed in English) says "הרשת הזו לא מופיעה ברשימת נקודות האיסוף של תאגיד מ.א.י." instead of the usual empty-state text (owner's decision). Whole words only.
- 2026-11-27 — In the details the distance sits right under the name, with no rule between them (gap ≤ 16 px). The carto ticket's spacing values kept a 1 px rule and 24 px of padding there, which could not meet its own 16 px check; the check won.
- 2026-11-27 — Cluster radius 70 / 55 / 48 / 20 px at zoom ≤ 9 / ≤ 13 / ≤ 15 / 16+. From 16, where a pick or "nearest" lands, only touching pins are grouped. `disableClusteringAtZoom` is not used: points on one exact coordinate must stay reachable through spiderfy.
- 2026-11-27 — No emoji in `app.js` or `index.html`; icons are inline SVG in `currentColor` (an emoji changes with every phone's font and brings colours from outside the design tokens). The check mark the confirmation sends to the form is written as `✔` in the source.
- 2026-11-27 — The map's credit line is one entry: the MAI credit, "עודכן <date>" from `data_meta.json` when it loads, then OpenStreetMap. No Leaflet prefix; Leaflet is credited in the README. Leaflet keeps credit entries in the order they were first added, so a separate date entry would have landed after the OSM credit.
- 2026-11-27 — The light basemap is `saturate(0.3) brightness(1.06) contrast(0.88)`, not full greyscale: the sea reads as sea and the pins and clusters stay the strongest colour (zoom 8 and 13 compared on a phone). (replaces the "desaturated" light basemap described in `CLAUDE.md`)
- 2026-11-27 — The scraper merges two records as one shop only when they have the same city. Two cities are never one shop: the merge hid the Haifa Ace (344152) inside 343950 "קריית אתא", and city overrides on merged records did nothing. One shop listed under two cities is settled by an override: the entry whose label does not fit its pin (Nominatim) is excluded (343950, 346211, 346441, 346634, 347313). (narrows the 2026-11-26 "one shop listed twice" entry)
- 2026-11-27 — A record without a house number that has two or more different house numbers of its chain within 50 m is merged with none of them: it could be any of those shops, and a merge would put one of them under the wrong pin and address (100 "אבי סופר, אלנבי" took both אלנבי 113 and 124). All of them stay. (narrows the 2026-11-26 "one shop listed twice" entry)
- 2026-11-27 — A previous `locations.json` that is there but cannot be read stops the refresh unless `--force`. It used to count as "no previous file", which switched the 90 % count guard and the 5 % change guard off.
- 2026-11-27 — The scraper reports overrides whose record is in the MAI response but never reaches the map (skipped, or merged away as the same point, shop or name, or stacked) in the run log and in `data_meta.json` as `overrides_without_effect`, with the reason. Not fatal: a merged-away record's override can come back to life when a rule changes. Overrides dead for a settled reason (records skipped as schools) are deleted; the rest stay.
- 2026-11-27 — The share preview is a 1200×630 opaque picture (`icons/og-image.png`): a screenshot of the real map over Tel Aviv with the logo and "מפת מיחזור סוללות · כ-3,600 נקודות איסוף בישראל", colours from the tokens, not precached. The page title says what the page is: "מפת מיחזור סוללות - נקודות איסוף סוללות בישראל". Descriptions in the head and manifest use neutral Hebrew ("איפה ממחזרים סוללות? …"), not "מצא". (design great-map P1)
- 2026-11-27 — Home-screen icons: one maskable 512 icon, full-bleed `--cw-data-cat-3` with the pin inside the central 80 %; an opaque 180×180 Apple touch icon; `icons/icon.svg` as SVG favicon; manifest `"id": "./"`. (design great-map P2)
- 2026-11-27 — A deploy reaches a returning visitor on their next visit, not the one after: the worker precaches with `cache: 'reload'` (GitHub Pages sends max-age=600, so the plain precache stored the old files under the new cache name), and a page the old worker served reloads itself once when the new worker takes over, but only while it has had no `pointerdown` or `keydown`. A page someone is using is never reloaded; it gets the new version next time. (design great-map P3)
- 2026-11-27 — The CSP allows images only from the site, `data:` and `https://tile.openstreetmap.org` (the one tile host both basemaps and `sw.js` use), with `base-uri 'self'` and `form-action 'none'`. A new tile host or a real form post must change the CSP in the same commit. The test pages are `noindex`. (design great-map P4)
- 2026-11-27 — On a phone held sideways (≤ 768 px, landscape) the details are a panel over the left half of the map, like the desktop sidebar, never over the map buttons and the credits on the right. A point that is shown (pick, link, nearest, tap) is centred in the part of the map the details leave free: half a sheet up on a phone, half a panel to the right with a side panel (`sidePanelWidth()`).
- 2026-11-27 — A page loaded with `?id=` whose history step already holds that point (a reload by hand, or the automatic reload after a deploy) opens it as from the history: no new step. Only a fresh link makes the plain page the step before the point. Before, every reload added one dead step to Back.
- 2026-11-27 — Picking a city (a suggestion, Enter on a city name, `?city=`) closes an open point first: its sheet, its selected pin and `?id=`, so the address carries the city. Typing text that is not a city leaves the point open. Each flight the app starts is counted (`mapMoveCount`); the `moveend` handler of an older flight does nothing, so a pick followed quickly by a search cannot pan back to the picked point.
- 2026-11-27 — A message (toast) never catches a tap (`pointer-events: none`; it is text only) and sits 80 px above the open sheet (`--sheet-h`), so it no longer covers the navigate buttons.
